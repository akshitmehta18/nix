Capabilities

Built Specifically for Spring Boot

Deterministic Tree-sitter AST parsing coupled with multi-provider LLMs provides zero-hallucination architectural understanding.

🌲

AST Structural Intelligence

Parses Java syntax trees with Tree-sitter. Extracts controller mappings, class hierarchies, and method signatures without relying on fragile regex.

🌐

REST Endpoints Discovery

Automatically indexes all @GetMapping, @PostMapping, @PutMapping, and @DeleteMapping routes with exact path variables and handlers.

🧩

Spring Bean Dependency Graph

Maps @Service, @Repository, @Component, and @Configuration beans, checking for proper constructor injection and wiring flaws.

🛡️

Static Security & Bug Auditor

Audits for JPA N+1 query patterns, missing @Transactional boundaries, unindexed queries, and field-injection anti-patterns.

🚀

Interactive HTTP API Tester

Built-in live request runner. Send GET, POST, PUT, DELETE payloads directly against your running Spring Boot service and view structured responses.

🩺

Error & Stack Trace Diagnostician

Paste NullPointerException or BeanCreationException traces to immediately locate the offending file, line number, root cause, and copy-paste fix patches.

              Quickstart
              
Get Started in 60 Seconds

              
Clone the repository and index your first Spring Boot project in three simple commands.

            


            

              

                

                  STEP 1
                  
Clone Repo

                  
Download the updated Nix repository from GitHub.

                

                

                  
git clone https://github.com/Mehtaji2004/nix.git

                  
                

              


              

                

                  STEP 2
                  
Install Global CLI

                  
Install Nix into your Python environment with all AST grammars.

                

                

                  
cd nix && pip install -e .

                  
                

              


              

                

                  STEP 3
                  
Launch Assistant

                  
Start the web server and open the live developer workstation.

                

                

                  
nix app --path nix/samples/demo_store

                  System Manual
                  
Configuration & Access Guide

                  
Everything you need to know about setting up LLM API keys, running CLI commands, and inspecting Spring Boot microservices.

                


                

                  

                    
🔑 Supported LLM Providers

                    
Nix automatically detects available API keys or falls back to its deterministic AST engine:

                    

                      export GROQ_API_KEY="gsk_..."

                      export GEMINI_API_KEY="AIza..."

                      export OPENAI_API_KEY="sk-..."

                      export ANTHROPIC_API_KEY="sk-ant-..."
                    

                  


                  

                    
💻 Local Offline Engine (Ollama)

                    
Run fully private, zero-cloud inference with Ollama on your Mac/Linux machine:

                    

                      ollama run llama3

                      nix config --provider ollama

                      nix scan
                    

                  


                  

                    
🚀 Pointing Nix to Any Spring Project

                    
Run Nix on any Spring Boot or Java Maven/Gradle project on your filesystem:

                    

                      nix app --path /Users/you/my-project

                      nix doctor

                      nix endpoints
                    

                  


                  

                    
📋 Global CLI Command Cheatsheet

                    
All commands available globally after pip install -e .:

                    

                      nix scan      # Parse Java AST

                      nix endpoints # List REST routes

                      nix beans     # Map dependencies

                      nix issues    # Security checks

                      nix app       # Start web studio
